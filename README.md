# The Coach — yayın kopyası

Bu depo YALNIZ derlenmiş oyunu taşır (`npm run build` çıktısı). Kaynak kod
burada değil, ayrı ve gizli bir depoda duruyor.

Oynamak için: https://melihyasir5-spec.github.io

Oyun tamamen tarayıcıda çalışır, sunucu ya da hesap gerektirmez. Kayıtlar
tarayıcının kendi deposunda (IndexedDB) tutulur, yani her cihaz ve her tarayıcı
kendi kariyerini tutar.
